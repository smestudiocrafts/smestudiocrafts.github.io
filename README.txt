SME STUDIO CRAFTS — ONLINE WEBSITE

This is a mobile-friendly, static website. Product photos are stored in the images folder.

IMPORTANT:
The WhatsApp number is currently set to 066 270 0631 (South Africa) and the email is SMEStudioCrafts@gmail.com, based on the 2026 catalogue.

HOW TO CHANGE PRODUCTS / PRICES / WHATSAPP:
1. Open index.html in a text editor.
2. Find const WA='27662700631'; and change the number if needed.
3. Find the 'products' array to change featured products, names and prices.
4. Find the 'catalogue' array to change catalogue items and prices.

The website does NOT collect customer photos itself. Customers are redirected to WhatsApp and can send their photos there, which matches the requested workflow.

HOW TO PUT IT ONLINE:
Upload index.html and the images folder to a static web host such as GitHub Pages, Netlify or Cloudflare Pages. A custom domain can then be connected later.
